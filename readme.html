🏫 업무자동화 가이드

한글 출결신고서 자동 생성 프로그램 (v0.9)

이 프로그램은 나이스(NEIS) 출결 현황을 기반으로 한글(HWP) 결석신고서를 자동 생성해주는 도구입니다.
📂 작업 폴더 준비 (C:\work)
로컬 디스크(C:)에 C:\work 폴더를 만드세요.

1단계: 파이썬(Python) 환경 구축

  • 파이썬 설치: python.org 접속 후 최신 버전 설치
  • ⚠️ 필수 체크: 설치 첫 화면 하단의 [Add Python to PATH]를 반드시 체크하세요.
  • 터미널 실행: 윈도우 검색창 cmd 입력 → 마우스 우클릭 -> [관리자 권한으로 실행]
  • 라이브러리 설치: 아래 명령어를 복사하여 검은 창에 입력 후 엔터
pip install pandas openpyxl pywin32 holidays

2단계: 나이스(NEIS) 데이터 추출

① 사유 선입력: [학급담임] > [출결관리] > [일일출결관리]에서 결석생의 사유를 미리 입력하고 저장했는지 확인하세요.(사유를 미리 입력하지 않으면 자동화 생성효율이 떨어집니다.)
  1. 메뉴 이동: [학급담임] > [출결현황및통계] > [학급별출결현황] > [월별] 선택 > 조회 > [월별 출결현황]
  2. 조회 설정: 월 선택 후, [셀병합] 체크박스를 반드시 '해제'하고 조회합니다.
  3. 엑셀 추출: [엑셀다운로드] 클릭 후 파일 이름을 월별 출결 현황.xlsx로 변경하여 C:\work에 저장합니다.

3단계: 한글 양식 및 파일 배치

C:\work 폴더에 아래 3개의 파일이 있어야 하며, 한글 양식은 아래 내용을 미리 수정해두세요.

  • auto_attendance.py (실행 코드)
  • 2026학년도 결석신고서.hwp (한글 양식)
    필수 작업 원본 양식 파일을 열어 [학과, 학년, 반] 정보는 미리 입력하고 저장해두세요. 성명과 번호, 날짜, 사유는 프로그램이 자동으로 채웁니다.
  • 월별 출결 현황.xlsx (나이스 파일)

4단계: 프로그램 실행

  1. 터미널 열기: 윈도우 검색창 cmd 입력 → 마우스 우클릭 -> [관리자 권한으로 실행]
  2. 폴더 이동 및 실행: 아래 명령어를 순서대로 입력합니다.
    3. cd c:\work
python auto_attendance.py
  3. 정보 입력: 담임 성함과 재량휴업일(예: 05-20)을 입력하면 output 폴더에 결과물이 생성됩니다.

⚠️ 주의사항

  • 실행 전 엑셀과 한글 파일이 열려 있다면 반드시 모두 닫아주세요.[cite: 1]
  • 한글 보안 승인 창이 뜨면 [모두 허용]을 클릭하세요.[cite: 1]
